# Башня Монолита — 100 этажей

Режим «Башня»: 100 этажей одного подъёма. Этаж = один забег на арене Монолита,
параметры врагов считает `data/tower_data.gd` (формат совместим с кампанией —
тот же конвейер run_params → ZoneController). Прогресс: этаж открывается после
победы на предыдущем, ранние этажи можно перепроходить ради звёзд.

## Особые этажи (хайп)

- **▲ Прорыв** — каждый 5-й этаж: статы ×1.08, награда ×1.5.
- **☠ Хранитель** — каждый 10-й этаж: именной босс яруса, статы ×1.15,
  +15% сталкеров, награда ×3.

## Звёзды: 1–3 за этаж

- ★ — победа.
- ★★ и ★★★ — по двум условиям этажа, детерминированно меняются от этажа к этажу
  (пул условий ниже). Условия показываются в панели башни и в подсказке этажа.

| Условие | Описание |
|---|---|
| Ни пятнышка | сталкеры не унесли ни одного артефакта |
| Своими руками | победа без единого выброса |
| Зачистка | перебить 75% сталкеров |
| Никто не уйдёт | перебить 90% сталкеров |
| Экономия / Скупо | создать не больше 4 / 8 мутантов |
| Богатый улов | заработать 1500 биомассы за забег |

## Награды

- **Биомасса**: (120 + 10×этаж) × множитель этажа (Прорыв ×1.5, Хранитель ×3).
- **Крутки мутантов**: (1 + этаж/20) × множитель + 1 за каждую звезду сверх первой.
- **Аномалийные крутки**: Хранитель +3, Прорыв +2, обычный этаж +1 (каждый третий).
- Поражение: половина биомассы, без круток.

Крутки питают существующую гачу (`GachaData`): мутанты — коллекция/ферма копий,
артефакты — коллекция/звёзды аномалий.

## Интерфейс

- Кнопка «🗼 Башня» в шапке лаборатории открывает панель: сетка 10×10 этажей
  (☠ Хранители, ▲ Прорывы, звёзды на пройденных), выбор этажа, условия и награды
  в подсказках и в инфостроке, кнопка «ИДТИ НА ЭТАЖ».
- Кнопка режима в селекторе циклит: Кампания → Башня → Выживание.
- Итоги этажа (звёзды, награды) показываются в панели результатов в лаборатории.

## Реализация

- `data/tower_data.gd` — весь дизайн в данных: ярусы, условия, награды,
  `get_floor_params()` (совместим с campaign_params), `evaluate_stars()`.
- `data/save_data.gd` — `tower_floor` (рубеж) и `tower_stars` {этаж: 1-3}.
- `core/game_manager.gd` — режим "tower" в `_setup_run_params`, `_apply_tower_result`
  (звёзды/награды/рубеж, крутки через `grant_mutant_rolls`/`grant_anomaly_rolls`).
- `zones/zone_controller.gd` — в результат забега добавлены `tower_floor`,
  `stalkers_total`, `stalkers_killed_sm`, `pulses_used` (нужны для звёзд;
  убитые/всего считаются одним источником — SpawnManager).
- `ui/lab/lab_controller.gd` — панель башни и интеграция в селектор режимов.

## Ручки баланса

Все константы в начале `tower_data.gd`: таблица `TIERS` (волны/количество/состав/
статы/боссы), пулы условий `EASY_POOL`/`HARD_POOL`, награды `REWARD_*`/`ROLLS_*`,
множители особых этажей `BREAK_*`/`KEEPER_*`.
