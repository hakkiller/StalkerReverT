Плюс ПК не имеет пакета графики №3 (210 .import с VRAM-сжатием и мипмапами,
colormap 1024, MSAA, туман 0.005, ACES/SSAO/glow, фиксы шейдера зерна).

### Обновление ПК (рекомендуемый путь — полная замена)
1. Закрыть Godot на ПК.
2. Старую папку проекта переименовать в резерв (например STALKER_REVERT_old).
3. Распаковать этот пак, папку STALKER_REVERT положить на прежнее место.
4. Перенести из резерва только личное: папку с сейвами не трогать — сейвы
   лежат в user:// (вне проекта), поэтому ничего переносить не нужно.
5. Открыть проект в Godot 4.6.1 — первый импорт дольше обычного (норма).
6. Запустить с открытой консолью, проверить: меню → лаба → ПРОФИЛЬ → гача.

### Чего в паке НЕТ (и не должно)
- Папка .godot (кэш импорта) — создастся сама.
- Папка .zcode (43 МБ мусора из вашего zip) — выброшена.
- Настоящие FBX-модели сталкеров и релизный keystore — только у вас,
  в исходниках стоят заглушки (как и было).
