# STALKER REVERT — пакет исправлений №3: ГРАФИКА («пиксели», серость, пропсы)

Копировать файлы поверх проекта с сохранением путей. Пак устраняет пять
конкретных причин плохой картинки, найденных по свежему дампу от 18.10.

**Допущение:** bloodsucker.gd (отступы) и pripyat_props.gd (_scatter_fences,
типы) в твоём свежем дампе УЖЕ починены ребятами — я их не трогал. Из старой
очереди в паке только showcase-фикс (он всё ещё был сломан).

## Диагноз: почему картинка была «хернёй»

### 1. ГЛАВНОЕ: все 3D-текстуры без мипмапов и без сжатия — вот твои «пиксели»

Проверил ВСЕ 380 импортов текстур в дампе. У 128 текстур, которые рисуются в
3D (весь пак PBR `assets/textures/pbr/`, декали, текстуры мутантов, эффекты),
импорт был такой:

```
compress/mode=0        (lossless, без VRAM-сжатия)
mipmaps/generate=false (без мипмапов!)
```

Текстура БЕЗ мипмапов в 3D — это классическая «пиксельная каша»: чем дальше
поверхность, тем сильнее каждый пиксель текстуры мерцает и сыпется. Земля с
трипланарной dirt_dry на весь экран без мипмапов выглядит как шум из битых
пикселей. Это и есть главный ответ на «что за пиксели я вижу».

Бонус-проблема того же импорта: без VRAM-сжатия текстуры едят в 4–8 раз
больше памяти — на телефоне это и фризы, и выгрузки.

**Фикс:** в паке 128 готовых `.import`-файлов с правильными параметрами
(`compress/mode=2` = VRAM Compressed, `mipmaps/generate=true`, для нормалей
`compress/normal_map=1`). Godot при открытии проекта сам переимпортирует их —
ничего нажимать не надо, просто дождись окончания прогресс-бара.

### 2. Туман душил всю картинку («серое молоко»)

`managers/fog_manager.gd` держал плотность тумана **0.02–0.08** при
светло-сером цвете (0.7, 0.75, 0.8). Экспоненциальный туман 0.02 на
дистанции 100 м съедает ~87% картинки. Камера RTS висит на 20–90 м и смотрит
на 100–300 м — в итоге весь мир был в молочной пелене (ровно как на твоём
скрине). Плюс высотный туман плотностью 0.5 на первых 3 м заливал саму землю.

**Фикс:** base 0.005, максимум 0.018, высотный — 0.12 на 2 м, цвет чуть
темнее (0.66, 0.70, 0.72). Атмосферная дымка остаётся, карта читается.
Ночь из выживания по-прежнему умножает плотность ×1.5 — учтено, логика
zone_controller не тронута.

### 3. Постэффект рисовал МЕРЦАЮЩИЕ БЛОКИ ~9 px («битые пиксели»)

В `shaders/grim_postfx.gdshader` было две технические бомбы:

- `screen_tex` сэмплировался с `filter_nearest` — при любом несовпадении
  разрешения копия экрана растягивалась ступеньками, блоки на весь экран;
- «зерно» считалось по крупной сетке `floor(SCREEN_UV * 220)` — на FullHD
  это квадраты ~9×9 px, которые мигают каждый кадр. Со стороны — ровно
  «битые пиксели», о которых ты пишешь.

**Фикс:** `filter_linear` + зерно 1:1 к пикселям экрана через FRAGCOORD
(мелкое, как плёночное и должно быть). Мрачный характер эффекта
(десатурация, тинт, виньетка, мерцение) сохранён без изменений.

### 4. Пропсы Припяти — СЕРЫЕ, потому что colormap — заглушка 4×4

Все 23 модели `models/props/*.glb` ссылаются на
`models/props/Textures/colormap.png`, а там лежит нейтральная заглушка 4×4
пикселя (это задание №10 из COMMANDS.md — оно всё ещё висело невыполненным).

**Фикс:** в паке готовый `colormap.png` 1024×1024 — бесшовный выветренный
бетон с ржавыми пятнами, копотью, намёком на мох и потёками (приглушённая
пост-советская гамма). Сделан единым материалом БЕЗ резких зон — это
сознательно: UV раскладки моделей я вслепую не знаю, и единая фактура
гарантированно не превратит половину автобуса в «дерево». Файл кладётся
ровно на место заглушки, .import у него уже правильный (VRAM+мипмапы),
Godot переимпортирует сам при смене PNG. Когда подготовщик принесёт
полноценный атлас по квадрантам (бетон/ржавчина/дерево/краска) — просто
заменишь PNG, а этот оставишь как фолбэк.

### 5. Сглаживание и анизотропия были выключены вообще

В project.godot не было ни MSAA, ни анизотропной фильтрации: рёбра зданий —
«лесенкой», земля под острым углом — мыльно-зернистая даже с мипмапами.

**Фикс (в project.godot):**
- `msaa_3d=2` — MSAA 4× на ПК;
- `msaa_3d.mobile=1` — MSAA 2× на Android (экономнее для батареи);
- `anisotropic_filtering_level=4` — земля и дороги читаются под острым углом.

## Что делать (5 минут)

1. **ПОЛНОСТЬЮ закрыть Godot.**
2. Скопировать содержимое пака поверх корня проекта (пути совпадают 1:1).
3. Открыть проект и **дождаться переимпорта** — Godot увидит новые `.import`
   и новые параметры, прогресс-бар в правом нижнем углу пробежит по
   текстурам (первый запуск будет заметно дольше обычного — это норма,
   переимпортируется ~130 текстур).
4. Запустить забег (лучше и Процедурную Зону, и Припять).

Удалять папку `.godot` в этот раз НЕ обязательно: переимпорт произойдёт и
так, по изменившимся `.import`. Если хочешь полный чистый прогон — можно
удалить, ничего не сломается.

## Что проверить при запуске

- Земля вблизи и ВДАЛИ: пиксельный шум/рябь на расстоянии должны уйти
  (мипмапы + анизотропия).
- «Битые пиксели»-блоки по экрану — исчезли, зерно стало мелким и мягким.
- Общая картинка светлее и читаемее, дальний край карты виден сквозь лёгкую
  дымку, а не в молоке.
- Монолит и аномалии — цвет и свет не изменились (их не трогал).
- Экспорт Android: ошибок «Showcase» быть не должно, APK соберётся чище.
- Пропсы в Припяти (машины, фонари, автобусы) — вместо ровной серости
  фактура бетона/ржавчины.

## Ручки, если захочется подкрутить

- **Туман гуще/реже** — `managers/fog_manager.gd`: `base_density`
  (0.003 = почти чисто, 0.01 = плотная дымка), `max_density`, цвет
  `fog_color`.
- **Зернистость** — `atmosphere/postfx_layer.gd`, строка
  `grain_amount` (сейчас 0.04 × strength; можно 0.0 — совсем без зерна).
- **Мрачность** — там же: `desaturation`, `wash`, `vignette_strength`.
- **Сглаживание** — project.godot: `msaa_3d` (2 = 4×, 3 = 8×, на слабом
  железе верни 1 = 2×).
- **Резкость текстур пропсов** — замени `colormap.png` на атлас от
  подготовщика (задание №10, квадранты бетон/ржавчина/дерево/краска).
