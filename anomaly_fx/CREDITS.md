# Лицензии и источники — anomaly_fx

## Ассеты пакета

Все файлы в этой папке (`shaders/`, `textures/`, `scenes/`, `scripts/`,
`demo/`) — **оригинальные процедурные ассеты, созданные специально для
проекта StalkerRevert** (генерация: Python/PIL для текстур, GDShader для
материалов). Никаких сторонних файлов внутри нет.

Лицензия: **CC0 1.0 (общественное достояние)** — разрешено всё, включая
коммерческое использование, указание авторства не требуется.

## Техники

Шейдеры используют стандартные приёмы компьютерной графики (fbm-шум,
френель, вертексный билборд) — это не охраняемые решения.

## Кандидаты на докачку (не включены, скачивание требует логина/руками)

- Sketchfab «Animated Crystal» (markskovrup) — лицензия автора на странице
- Sketchfab коллекция «PORTAL» (metaclubmedia) — лицензии на страницах моделей
- BlendKit «Animated Blue Vortex Portal» — по странице ассета
Эти источники НЕ входят в пакет; если основной агент их скачает — лицензию
прописать здесь же отдельной строкой.
