# Пак звуков для SoundManager (ЗАДАЧА 1)

Все ключи = имена файлов. SFX: `sfx/<ключ>.ogg`, музыка: `music/<ключ>.ogg`.
Формат: OGG Vorbis, 44.1 кГц, стерео. Громкость нормализована: обычные
SFX −18 LUFS, `ui_hover` −20, лупы аномалий −26, музыка −24 (TP −1.5 дБ).

## Состав

### UI (sfx/)
- `ui_hover` — тихий короткий тик (50 мс)
- `ui_click` — клик (низкий тук + тик)
- `upgrade` — позитивное трезвучие (арпеджио A4–C#5–E5, колокольный тембр)
- `exchange` — монеты: россыпь металлических пингов + шелест

### Выброс
- `pulse_warning` — 4.2 с: разгоняющаяся двухтоновая сирена + нарастающий гул

### Аномалии (ЗАЦИКЛЕНЫ, бесшовный луп, тихие)
- `anomaly_electric` — гул 50 Гц + треск разрядов + редкие дуги (7 с)
- `anomaly_thermal` — низкий рокот + треск огня + шипение (7 с)
- `anomaly_gravity` — бьющиеся детюн-дроны 41/42.7 Гц + субы + вжух (8 с)
- `anomaly_chemical` — пузыри вверх/вязкие глупы вниз + шипение (7 с)
- `anomaly_radiation` — щелчки Гейгера пачками + тонкий гул 1 кГц (7 с)

### Мутанты (рык/голос, 0.8–2.0 с) — записи с OpenGameArt
- `mutant_bloodsucker`, `mutant_flesh`, `mutant_snork`, `mutant_pseudodog`,
  `mutant_controller`, `mutant_poltergeist`, `mutant_chimera`, `mutant_zombie`

### Шаги (по 6 вариантов на поверхность, питч-рандомизация на вашей стороне)
- `step_grass_01..06` — мягкий шелест травы
- `step_stone_01..06` — щелчок + короткий стук
- `step_sand_01..06` — песочная крошка (гранулярная)
- `step_water_01..06` — всплеск + капли

### Музыка (music/, ЗАЦИКЛЕНА, бесшовный луп)
- `music_menu` — 119 с: медленные минорные дроны, ветер, редкие глубокие удары
  и дальние металлические пинги
- `music_lab` — 119 с: дроны + сетевой гул 50 Гц + мягкий пульс раз в 2 с
- `music_run` — 149 с: тревожный низкий пульс ~57 bpm («сердцебиение»),
  ветер, дальние свипы, щелчки статикой

## Происхождение и лицензии

- Всё, кроме голосов мутантов, — оригинальная процедурная генерация
  (синтез), лицензия CC0, ограничений нет (см. CREDITS.md).
- Голоса мутантов — записи с OpenGameArt, у каждого указаны автор и лицензия
  в CREDITS.md; два файла под CC-BY 3.0 — при использовании оставляйте
  атрибуцию из CREDITS.md.

## Технические заметки

- Лупы сведены с кроссфейдом хвоста в голову (equal-power), стык на слух
  бесшовен; при подключении ставьте `loop = true`.
- Длинные лупы аномалий намеренно тихие (−26 LUFS) — это эмбиент-подложка,
  громкость события (удар аномалии) поверх неё.
- «Самый громкий кусок» для голосов мутантов вырезан автоматически из
  исходников; если какой-то рык сядет неточно по характеру — скажите,
  подберу другой исходник вручную.
