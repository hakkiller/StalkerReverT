# Скайбоксы зоны (ЗАДАЧА 3)

Четыре панорамных HDRI-скайбокса в духе зоны отчуждения. Формат: Radiance
`.hdr` (RGBE, float), equirectangular 2:1, **4096×2048** (4K), проверены
заголовки и md5. Подходят для `PanoramaSkyMaterial` (Godot) и как источник
окружающего освещения/reflection probe (environment).

## Файлы

| Файл | Что это | Настроение | polyhaven ID |
|---|---|---|---|
| `sky_overcast_gloomy_4k.hdr` | **Основной**: мрачный пасмур над полями/фермой | ровный серый свет, тихая угроза — дефолт для забега | farmland_overcast |
| `sky_dawn_misty_4k.hdr` | Рассвет в тумане (лес, река, ЛЭП) | холодный молочный туман, низкое солнце — утренние уровни | misty_dawn |
| `sky_storm_gloomy_4k.hdr` | Гроза над каменоломней с озером | самый тёмный, тяжёлые тучи — выброс/штормовые события | quarry_cloudy |
| `sky_overcast_02_4k.hdr` | Второй пасмур (каменистая пустошь) | вариация основного для разнообразия биомов | rogland_overcast |

Все четыре — тип **HDR**, лицензия **CC0** (см. CREDITS.md).

## Рекомендации по подключению

- Основной вариант — `sky_overcast_gloomy_4k.hdr`: пасмурное небо, под
  горизонтом поле — при камере RTS низ панорамы закрыт террейном.
- Для «рассветных» и «штормовых» состояний погоды — переключать
  `PanoramaSkyMaterial.panorama` на соответствующий файл.
- Эти же HDR можно оставить как `background_energy`-источник мягкого
  света: пасмурные сцены дают низкий контраст, который ложится в стиль.
- Размер 4K достаточен и для неба, и для отражений; если понадобятся 8k+ —
  они есть на страницах polyhaven (ссылки в CREDITS.md).
