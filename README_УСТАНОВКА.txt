STALKER REVERT — ПАК «ВСЁ В БУНКЕРЕ» (меню 4 + лаба 4 + гача 4)
================================================================

ЧТО ВНУТРИ
----------
Весь интерфейс переведён на выбранный стиль БУНКЕР (вариант 4):
стальные панели, хазард-полосы, 3D-кнопки, штампы, шрифты
Russo One / Oswald / JetBrains Mono.

1. ГЛАВНОЕ МЕНЮ — бункерный пультовый зал, штамп «ДОСТУП РАЗРЕШЁН»,
   пластины ресурсов (биомасса / крутки / коллекция), зелёная 3D-кнопка.
2. ЛАБОРАТОРИЯ — тот же стиль + ДЕКА ГАЧИ: большая жёлтая кнопка
   «ГАЧА ЗОНЫ», пластины круток, подсказка о джекпоте.
3. ГАЧА ЗОНЫ — НОВЫЙ ОТДЕЛЬНЫЙ ПОЛНОЭКРАННЫЙ УЗЕЛ:
   - два рукава: МУТАНТЫ / АНОМАЛИИ (переключение, лампы, счётчики);
   - капсула доставки с джекпот-картой Химеры и рамкой редкости;
   - шкала гарантии Химеры (ур.50), до ур.30 исключена;
   - таблица шансов по уровню кампании (рост легендарок до 12%);
   - последние доставки с цветами редкости и статусами
     (НОВЫЙ / копия / +1 звезда);
   - коллекция 0-28 из НАСТОЯЩИХ карточек игры (серые = закрыты);
   - кнопки КРУТИТЬ ×1 / ×10 (механика GameManager без изменений);
   - бонус артефактов теперь реально капает: биомасса в лабораторию.

УСТАНОВКА
---------
1. Скопируйте СОДЕРЖИМОЕ папки pack в КОРЕНЬ проекта Godot
   (там, где project.godot) — с заменой файлов.
2. project.godot замените целиком: в нём графика из пакета №3
   (MSAA/анизотропия) + окно 1920x1080 + растяжка canvas_items +
   датчик-ландшафт для телефона. Макет рассчитан на эти настройки.
3. Откройте проект в Godot 4.6.1 — новые ресурсы (шрифты, SVG)
   импортируются автоматически.
4. Пересоберите APK как обычно. Если ключ подписания менялся —
   удалите старую игру перед установкой.

ВАЖНО
-----
- Все механики сохранены: башня 1-100, выживание, кампания,
  станции, магазин, ферма, звёзды, утилизация — ничего не вырезано.
- Вход в гачу: ЛАБОРАТОРИЯ -> жёлтая кнопка «ГАЧА ЗОНЫ».
  Выход: кнопка «НАЗАД» внизу слева гачи.
- PNG-карточки художника ставятся автоматически, если лежат
  в ui/cards (обязательства нет — работает и SVG-фоллбэк).

ПРОВЕРЕНО
---------
- 107/107 скриптов компилируются (Godot 4.6.1 headless).
- Smoke-тест: main_menu.tscn, lab.tscn, gacha.tscn — все узлы на месте.
- Реальные скриншоты движка: см. БУНКЕР_все_экраны.png рядом с паком.
