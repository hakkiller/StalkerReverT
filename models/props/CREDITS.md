# models/props — уличные пропсы для карты Припяти

23 low-poly `.glb` с материалами, реальный масштаб в метрах, origin в
основании, машины вытянуты по Z. Доставка: агент-подготовщик (задание 2
`COMMANDS.md`, `inbox/_done/pripyat_props/` — там же README с габаритами).
Раскладчик: `terrain/pripyat_props.gd`, плотности: `data/pripyat_props_data.gd`.

Модификация источников — только нормализация (масштаб/origin узлом-обёрткой
`normalized` внутри glb; геометрия и материалы не менялись).
